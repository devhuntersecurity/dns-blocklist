# 🤝 Contributing Guide — DevHunter DNS Blocklist

Thank you for contributing to the DevHunter DNS Filtering Dataset.

This project maintains a structured dataset for DNS-level filtering using Unbound.

---

## 📌 What You Can Contribute

- 🚫 New malicious / phishing / malware domains
- 🎰 Gambling domains
- 🔞 NSFW domains
- 📢 Ads & tracking domains
- 🚫 Malicious IP addresses
- ✅ Whitelist (false-positive fixes)

---

## 🧾 Contribution Rules

Please follow these rules:

- One entry per line
- No duplicates
- No invalid domains/IPs
- Do not include comments in data files
- Respect existing category structure

---

## 📬 How to Submit

Use GitHub Issues:

- 🧾 Blocklist Request
- ✅ Whitelist Request
- 🐞 Bug Report

All submissions are reviewed before merging.

---

## ⚠️ Important

This is a **DNS filtering dataset only**, used with Unbound DNS Resolver.

Do not submit unrelated firewall or application-layer rules.

---

Thank you for helping improve this dataset.
